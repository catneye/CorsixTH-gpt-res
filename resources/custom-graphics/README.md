# Custom graphics workspace

This directory is reserved for original assets created for this project.

Planned subdirectories:

- `source/` — editable source artwork (for example, layered files).
- `sprites/` — exported sprite sheets with transparency.
- `animations/` — animation definitions and frame sequences.
- `build/` — generated CTHG files; generated output should be reproducible.

No Theme Hospital original sprites or extracted game graphics belong here.
